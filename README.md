# Canelo Wind 🪁

Viento, rachas y olas para windsurf, kitesurf y wing foil en los spots de Canarias, la península y Baleares.
Hecha pensando en Miki «el Canelo».

- Elige un spot y mira la previsión hora a hora para los próximos 7 días: viento, rachas, dirección, olas, mar de fondo y tiempo.
- Marca si la dirección del viento es buena para ese spot.
- Enlaces a anemómetros (viento medido ahora) y webcams de cada zona.
- Los usuarios pueden reportar cómo está el spot y mandar sugerencias.

Datos de previsión: [Open-Meteo](https://open-meteo.com/) (gratis, sin clave).

## Archivos
- `index.html` — la app.
- `spots.js` — lista de spots (para añadir uno, copia un bloque).
- `config.js` — enlaces de los formularios de Google (reportes y sugerencias).
- `logo.svg` — el logo.
